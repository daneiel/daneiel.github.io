# daneiel.github.io

**Português** · [English](README.en.md) · [中文](README.zh-CN.md) · [Русский](README.ru.md)

Site pessoal de Daniel Souza, publicado pelo GitHub Pages em **https://daneiel.github.io/**. HTML, CSS e JavaScript estáticos, sem build.

## O que tem aqui

| Caminho | Página | Origem |
| --- | --- | --- |
| [`index.html`](index.html) | [Portfólio](https://daneiel.github.io/): apresentação, projetos, sobre, tokens de design e contato | este repositório |
| [`virapets/`](virapets/) | [ViraPets Studio](https://daneiel.github.io/virapets/): criador de mascotes em pixel art (desenho procedural, foto local em pixel art e figurinhas), funciona offline | [viralabs-dev/virapets](https://github.com/viralabs-dev/virapets) · [guia](https://github.com/viralabs-dev/virapets/blob/main/site/README.md) |
| `/brabo/` | [Documentação do Brabo](https://daneiel.github.io/brabo/) | publicada pelo próprio repositório [daneiel/brabo](https://github.com/daneiel/brabo) |

## Rodar localmente

```bash
python3 -m http.server 8000
# abra http://localhost:8000/ e http://localhost:8000/virapets/
```

## Publicação

O GitHub Pages serve a branch `main` na raiz. Um push na `main` publica o site.
